# Temple fragment action

The artist selected a border assembled from independently generated oblique pieces: some shared edges and uneven gaps, no continuous snake. Pieces drift around the perimeter, with neighbour pressure keeping them distributed. Hover/focus/press aligns each real straight cut at its current location (50ms in,300ms out). Rotation anticipates corners. Click scatters the pieces, then grows them back into the live border after a pause. Eleven pieces share the poem's warm/cool ink range, with a slight per-piece gradient. The shared palette maps onto each theme's existing text base. Reduced motion freezes travel and substitutes a short opacity response for the click effect.

Requested integration: “mit origin/main integrieren … einen ‘join me in person’ button nach der ersten strophe”. The optional `PoemPair.action` colocates the supplied label/contact link with the relevant content. `FirstPair` renders this action after its complete verse/refrain/coda; the existing final pause contains the action. The first authored pair links to the artist's supplied `sound@hannesdiem.de`. No other invitation copy or location studies are included.

`FragmentAction` is an ordinary component within the existing Opening island, using its own task signal. The native anchor is present and usable in server-rendered/no-JavaScript output. Each instance gets one random seed unless content supplies `action.seed`; geometry and colour remain stable during layout updates. No editor storage or gallery controls are shipped.

- `fragment-generator.ts`: seeded oblique shapes and mixed-border placement; actual edge/contact geometry.
- `border-flow.ts`: independent perimeter travel with bounded neighbour gaps and smooth corner orientation.
- `border-motion.ts`: one visibility-aware frame loop, precise alignment and click state. Observers/listeners/RAF stop on disposal; no hidden/offscreen catch-up.
- `fragment-burst.ts`: scatter/absence/staggered zoom phases; final geometry is restored exactly.
- `action.tsx` / `style.css`: native anchor, decorative SVG and layout/theme integration.
- `material.ts`: shared soft rounded joins and a page texture made from the first button's exact paths at2400% size, with partial overlaps. Six pieces occupy a1920×1600px tile; seeded positions/rotations repeat seamlessly, with subtle shade variation per theme. Individual SVG copies retain their real bounds and shared layer assignment.
- `ground-motion.ts`: native scroll timelines add slight depth between layers and open black space for each chorus, without per-scroll JavaScript positioning.
- `ground-signal.ts`: one occasional travelling dash and fading edge trail, attached to the actual drifting piece. Shared placement data keeps it aligned without scroll-position writes or a new frame loop.

`ground.ts` puts the shared texture in nested native sticky layers, one per refrain. Each layer is shorter than its parent by that refrain's hold distance; its negative sticky top matches the centred reading position, accounting for earlier holds. The browser pauses and resumes the ground continuously in both directions. Dimensions are calculated at startup/layout changes only: no scroll-position writes, mode switches, extra frame loop or scroll interception.

Three CSS parent planes drift26–40px over95–117second cycles, with different directions and phases. The pieces start beyond the sides during the opener. From0.3viewport of scroll they travel continuously across the entire first verse, clearing the viewport40% into the first chorus's actual sticky hold. Native transforms animate the SVG pieces consistently across browsers; SVG-internal animation was rejected after Chromium ignored the image's reduced-motion query and WebKit did not animate it. The page's own media query fully disables drift for reduced motion. Background motion does not change the native scroll hold. Shared1.8-unit rounded joins soften both button and background edges without changing the straight cuts used for alignment.

Each piece now has a slight static diagonal gradient: background tones shift by four channels end to end; button gradients sample the same channel mapping and variance as the poem's ink clouds. The artist clarifies that edge richness means an occasional travelling signal, not permanent glowing borders or pulsing surfaces. The first eligible signal starts after1.2seconds; subsequent signals have1.25–1.75seconds of travel,1.5seconds of fading trail, and1.2–3seconds of quiet. Their warm amber/brown hue follows the existing subtle alpha values in both themes. Tip/trail opacity is roughly halved from the initial trace study. Only one exists globally. A masked SVG draws the outer rim of the actual rounded silhouette; it lives inside the actual moving piece so drift/scroll/exit alignment needs no repeated JavaScript positioning. Forty cached points per shape, projected through its native SVG screen matrix, select an edge with a visible portion. Reduced motion, hidden documents and disposal clear the signal and timer.

`ground-pieces.ts` renders the six logical seeded placements as individually bounded SVGs, repeated at the existing tile spacing across the document. The first button publishes its material through a host-scoped weak reference/event; rendering works regardless of parent/child task order. Layout changes rebuild the decorative copies and their native animations. Each copy's projected bounds determine the actual fully hidden entrance and exit distances, with a small drift margin. Avoid extra exit overshoot, which would clear a shape before its scene-linked endpoint. This replaces moving a full texture layer, which could carry pieces across the centre and cut them at the layer bounds. Shapes, rounded joins, shades, scale, density, ambient drift, parallax and scroll timing remain the same. There are no per-scroll JavaScript position writes or new RAF loops. One trace is attached inside its actual SVG rather than to an independently moving texture plane.

The current movement uses two opposing through-currents, entering from both sides and leaving through the opposite side. Earlier versions made only the short entrance/exit segments linear and still paused at a neutral middle position. The artist explicitly rejected that model. The whole verse now shares one constant horizontal velocity per piece; there is no entrance/linger/exit choreography or separate settling window. Regression coverage samples actual SVG displacement across five positions in each full synthetic verse and compares velocity, in both viewport sizes, with JavaScript RAF deliberately stalled. It also covers clear chorus holds, the offscreen reset, reverse travel, reduced motion and trace cleanup.
